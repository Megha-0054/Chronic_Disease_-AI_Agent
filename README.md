# 🩺 Chronic Disease Prediction AI

This project is an AI-based predictive model built using **IBM WatsonX**, **IBM Granite**, and **IBM Cloud** services. It analyzes health-related data to help identify the likelihood of chronic diseases, aiming to support early intervention and smarter healthcare decisions.

## 🧠 Features
- Predicts risk of chronic diseases using trained ML models
- Built on IBM Watson Studio and Granite foundation models
- Utilizes object storage for scalable dataset management
- Trained with real-world health datasets (CSV format)

## 🛠 Technologies Used
- IBM Cloud Object Storage
- IBM WatsonX / Watson Studio
- Python (Jupyter Notebook `.ipynb`)
- Pandas, Scikit-learn, Matplotlib

## 📁 Files
- `Chronic_Disease.ipynb` — Main notebook for training and prediction
- `dataset.csv` — Health dataset used for model training and testing (upload separately)

## 🚀 How to Run
1. Upload the notebook to IBM Watson Studio or run locally in JupyterLab.
2. Make sure the dataset is placed correctly and paths are updated.
3. Run all cells to train the model and test predictions.
